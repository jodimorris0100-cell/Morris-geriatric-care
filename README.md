🌿 About

Morris Geriatric Care & Senior Consulting provides compassionate, person-centered guidance for older adults and their families.

The website is designed to communicate trust, professionalism, dignity, and warmth while making it easy for prospective clients and families to learn about services and get in touch.

🩺 Services

Geriatric Care Guidance

Nursing-informed guidance focused on the safety, wellbeing, daily needs, and quality of life of older adults.

Care Coordination

Support with organizing appointments, services, family communication, and the different aspects of senior care.

Senior Consulting

Practical guidance for families navigating changing care needs, transitions, and important senior-care decisions.

💚 Our Philosophy

Every older adult deserves to feel heard, respected, safe, and supported.

Morris Geriatric Care & Senior Consulting takes a person-centered approach to aging and senior care.

🚀 Getting Started

Replace YOUR-USERNAME with your GitHub username:

git clone https://github.com/YOUR-USERNAME/morris-geriatric-care.git
cd morris-geriatric-care

Then open index.html in your browser. No build process is required.

🌐 GitHub Pages

This website is designed to work with GitHub Pages.

Upload index.html and README.md to your repository.

Open Settings.

Select Pages.

Under Build and deployment, choose your main branch.

Save the settings.

GitHub will provide your published website address.

A custom domain can be connected later.
